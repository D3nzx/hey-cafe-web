# Hey! Cafe Website: How It Works

The website will give customers a simple, mobile-friendly place to browse the cafe's menu and find confirmed cafe information. It is a menu and information site, not an online ordering or payment system.

Updating the menu

An authorized cafe editor can sign in to the content editor using a browser. They can add or update menu categories and items, prices, descriptions, availability, and photos without editing website code. After reviewing the changes, the editor publishes them. The website then rebuilds, and the published changes appear after that build finishes. Updates are not instant; they usually take a few minutes after publishing, depending on the hosting service.

The editor can also hold an optional public menu PDF. Only approved, public business information and files should be published there. Private or internal documents should not be uploaded.

Cost and hosting

There is no charge from me for the initial website project. The current plan is to use the free tiers of Sanity for menu editing and Cloudflare Pages for website hosting, with a free hosting address rather than a purchased custom domain. GitHub's free plan can be used for the project source code.

Sanity currently shows a Growth trial and says the project will automatically move to its Free plan at the end of the trial, at $0 per month. The Free plan shown in the account includes up to 20 user seats, two permission roles, and two public datasets. The website only needs a public dataset for approved content. The project should remain within the providers' free-plan limits; plans, limits, and terms may change over time.

No paid plan, paid add-on, or custom domain will be purchased without the cafe's agreement. A custom domain (for example, a cafe-owned .com address) is optional and normally has a separate registration cost. If a provider changes its free offering or the project outgrows a free limit, we will discuss the options before incurring any cost.

Maintenance and ownership

Basic menu and price edits can be made by an authorized cafe editor in the content editor without a developer. The initial handoff and project are being provided at no charge. Ongoing technical maintenance, new features, or substantial changes are not included as a guaranteed permanent service; any future work or cost would be discussed and agreed in advance.

Before launch or entering real cafe content, the cafe should have appropriate access and control of its content and service accounts. Menu details, prices, photos, hours, location, and contact links will only be added as real information after the cafe supplies and approves them.

Current status

The website and local content editor are prototypes and are not yet deployed publicly. The Sanity project is connected locally for setup and testing. Before launch, the cafe's access and ownership arrangements, approved content, hosting deployment, and publishing flow still need to be completed and tested.
