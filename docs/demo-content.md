# Hey! Cafe — Demo Content for Client Preview

This file contains the sample menu data used to populate the Studio for client demonstration.
The four categories and 16 menu items are currently published as clearly fictional preview content and may be replaced with approved cafe data after owner review.

> The live-site label and Studio preview distinguish this demo content from confirmed cafe information. Do not present these names, prices, descriptions, or photos as the cafe's final offerings.

## Step 1 — Add Categories

Go to **Menu Category** in the Studio sidebar and add these four entries.
Fill in the Name, click **Generate** for the Slug, set the Display Order, toggle **Active on**, then **Publish** each one before moving to the next.

| Name | Slug | Display Order | Active |
| --- | --- | --- | --- |
| Espresso | espresso | 1 | ✅ |
| Signature Drinks | signature-drinks | 2 | ✅ |
| Non-Coffee | non-coffee | 3 | ✅ |
| Pastries | pastries | 4 | ✅ |

## Step 2 — Add Menu Items

Go to **Menu Item** in the Studio sidebar. For each item:

1. Fill in Name, click **Generate** for Slug
2. Select the correct **Category**
3. Enter the **Price** (numbers only, no ₱ sign)
4. Add the **Description**
5. Upload a **photo** (see Step 3 for where to get photos)
6. Fill in the **Image Alt Text**
7. Toggle **Available** on
8. Set **Featured** as indicated
9. Set **Display Order**
10. Click **Publish**
